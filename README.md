# MAKASE AI Studio — Phase 2（施設候補管理）

日本在住18〜34歳向けの投稿テーマを企画し、承認して制作進捗・施設候補を管理する日本語Streamlitアプリです。**Python 3.12（64bit）を推奨**します。Windows用バッチは3.12を使用します。開発時のテスト環境はLinux・Python 3.12です。Phase 1のWindows起動成功はユーザーから報告されていますが、このPhase 2更新版のWindows実機検証は未実施です。SQLiteはPython標準付属です。

## Phase 1からWindowsで更新する

1. アプリの起動ウィンドウで `Ctrl+C` を押して停止し、ほかにMAKASEが起動していないことを確認します。
2. `data`フォルダ全体を別の場所にコピーしてバックアップします。`MAKASE_DB_PATH`を設定した場合は、そのDBと同じ場所のWAL／SHMファイルも含めて退避します。既存のソースも別途退避してください。
3. Phase 2更新ZIPを別の場所へ展開し、その中の`app.py`・`studio`・`tests`・`README.md`・`docs`を**現在使用しているプロジェクトへ上書きコピー**します。プロジェクト内にもう一つ同名フォルダを作るのではなく、既存`app.py`と同じ階層に配置します。`.venv`・`data`・`.env`・独自のStreamlit設定は置き換えないでください。Git更新の場合も、まずローカル変更とDBを退避し、変更が公開された後にのみ更新してください。
4. 今回、依存パッケージは追加していません。既存の`start_windows.bat`で起動できます。DBの新テーブルは「施設候補リサーチ」を最初に開いたときに自動作成し、既存のテーマ・承認履歴・進捗・投稿実績は残します。
5. Phase 1の一覧が残っていることを確認し、承認済みテーマを選んで施設候補を登録してください。新メニューが表示されない場合は、起動したフォルダと上書き先が一致しているか確認してサーバーを再起動します。

元の版に戻す場合は、アプリを停止して退避したソースへ戻します。旧版は新しい施設テーブルを使いません。更新後に保存したデータを失わないよう、DBのバックアップを復元する場合は復元時点も確認してください。更新作業はWindows実機では未検証です。

## Windowsで起動する

### ダブルクリックで設定・起動

1. [Python公式サイト](https://www.python.org/downloads/windows/)からPython 3.12の64bit版をインストールします。Pythonランチャー（`py`）を含めるか、`Add python.exe to PATH`を有効にしてください。既にPythonがある場合はPowerShellで `py -3.12 --version` を確認します。
2. ソースZIPをダウンロードした場合は、**ZIP内から直接実行せず**、すべてを `C:\MAKASE\ChatGPT1` など書き込み可能なフォルダに展開します。GitHubのファイルはpush完了後に利用できます。ソースZIPには個人データやPython本体は含まれません。
3. 初回だけ `setup_windows.bat` をダブルクリックします。Python 3.12を確認し、`.venv` に依存パッケージをインストールします。初回はインターネット接続が必要です。`Setup completed` と表示されたことを確認します。
4. `start_windows.bat` をダブルクリックします。ローカルサーバーを起動し、Streamlitにブラウザを開かせます。自動で開かない場合は、ウィンドウに表示されるアドレスをブラウザに入力してください。
5. 終了するときは起動ウィンドウで `Ctrl+C` を押します。2回目以降は `start_windows.bat` だけで起動できます。起動用バッチは依存関係のインストールやデータ消去を行いません。

バッチのメッセージは文字化けを避けるため英語です。管理画面は日本語です。バッチは管理者権限やPowerShellの実行ポリシー変更を必要としません。

### PowerShellで手動起動

このリポジトリをダウンロード／cloneして展開したフォルダでPowerShellを開きます。以下は仮想環境の有効化が不要な手順です。

```powershell
cd C:\path\to\ChatGPT1
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run app.py --server.address 127.0.0.1
```

ターミナルに表示されるアドレスをブラウザで開いてください。終了は `Ctrl+C`。2回目以降は最後の起動コマンドだけで利用できます。SQLiteの別サーバーは不要です。

### 起動できないとき

- Pythonが見つからない：Python 3.12とランチャーをインストールしてターミナルを開き直します。`python` でMicrosoft Storeが開く場合も、`py -3.12` が使えるか確認してください。
- 別環境の`.venv`がある：Linuxからコピーした仮想環境はWindowsでは使えません。アプリを停止して`.venv`だけを退避・削除し、`setup_windows.bat`で作り直します。**`data`は削除しないでください。**
- インストールに失敗する：通信・プロキシ・空き容量とエラーを確認し、`setup_windows.bat`を再実行します。TLS証明書検証を無効にしないでください。
- 8501番が使用中：既に起動しているMAKASEのウィンドウを確認してください。他のアプリを停止せずに別ポートで使う場合は、手動起動コマンドの末尾に `--server.port 8502` を付けます。
- 再インストールが必要でもDBはそのまま残してください。環境変数`MAKASE_DB_PATH`を設定している場合は、その保存先も確認します。

## 使い方

1. 必要に応じて「過去の投稿実績」に、投稿タイトル・ジャンル・投稿日・再生数・いいね数・保存数を登録します。
2. 「AI投稿テーマ企画」で企画対象日・重点ジャンル・任意メモを指定し、「テーマ10案を作成」を押します。10案と企画条件はその場でDBに保存されます。
3. 各テーマの点数・理由・構成を確認し、「承認」「修正を保存」「却下」を選びます。テーマ名・構成・判断理由も同時に保存されます。「修正済み」は再承認が必要です。承認取り消し時は制作進捗が未着手に戻ります。
4. 「投稿制作の進捗管理」で承認済みテーマの進捗・メモを更新します。進捗は未着手／構成作成／素材準備／編集／確認待ち／完成／投稿済みの7段階。必要に応じて前の段階にも戻せます。
5. ダッシュボードで承認待ち・制作中・投稿済みの件数を確認します。過去の企画も企画履歴から再表示できます。

## 施設候補リサーチ

1. 「施設候補リサーチ」で承認済みテーマを選び、「施設候補の新規登録」を開きます。施設名・住所・公式URL・施設情報・料金条件・公式情報の確認日・候補の状態・比較メモを保存できます。確認日は未来日を指定できません。
2. 複数の施設を登録して、「比較する施設」で対象を選びます。所在地・特徴・料金条件・出典数・利用可の写真数などを同じ表で比較できます。候補の状態は「検討中／優先候補／見送り」です。情報の正確さや候補の優劣をAIが判定する機能ではありません。
3. 施設の詳細から、営業時間などの項目ごとの確認情報・出典URL・確認日・メモを登録・修正します。施設の基本情報も後から編集できます。古い画面による上書きはバージョン照合で防ぎます。
4. 写真候補は写真名・掲載元URL・権利者・許諾状況・許諾の根拠・許諾された用途・クレジット・任意の利用期限・メモを保存します。画像の自動取得・ダウンロード・埋め込み表示はしません。写真ファイル自体をこの画面にアップロードする機能もありません。
5. 「利用可」には権利者・許諾の根拠・用途が必要です。期限を過ぎた写真は自動で「期限切れ」と表示し、利用可の件数から除外します（期限当日は含みます）。未確認・利用不可・期限切れも候補記録として残せます。「利用可」は入力者が記録した許諾内容の状態であり、あらゆる媒体への利用を保証しません。
6. テーマの承認を取り消すと、紐づいた施設情報は残したまま閲覧専用になります。再承認すると編集できます。

施設の公式情報を優先し、料金は日付・人数・部屋・食事・税などの条件と一緒に記録してください。投稿前に最新情報と素材の許諾範囲を確認します。一休.com・Trip.comの自動収集、写真転載、外部投稿は実装していません。Canvaのプラン変更や有料契約も不要です。[調査方針](docs/phase2-research-plan.md)を参照してください。

## 無料テストモードと今後のAI接続

- 現在は**AI未接続のルールベース・テストデータ生成**です。有料API、APIキー、外部AIリクエストを使用しません。初回の依存パッケージ取得以外はオフラインで動きます。課金サービスや有料リソースの作成も行いません。
- 月別の季節・固定イベント候補と、忙しい若年層向けの生活・予算・短時間の観点から10案を作成します。同じ条件では同じ案になります。実在イベントの開催日、最新トレンド、医療上の有効性などは取得・保証しません。
- 参考スコア = 基本65 ＋ 重点ジャンル一致10 ＋ `min(20, round(100 × (いいね合計＋保存合計) / 再生合計))`。実績のないジャンルの加点は0です。ジャンル別の合計値を使い、過去実績のない架空の成功を表示しません。反応率はいいねと保存が重複する場合があります。スコアは再生数や成功率の予測ではありません。
- 任意メモは企画条件として添付します。テストモードは自由文の条件を解釈して案を変更しません。条件への適合は制作前に確認してください。
- `studio/generator.py` の `ThemeGenerator` Protocolが交換口です。画面は`studio/planning.py`の`generate_and_save()`を呼び、生成器の選択は`get_generator()`に集約しています。無料モデルへ切り替えるときに画面・DBの変更は不要です。
- `JsonThemeGenerator(complete, model_name)`は、プロンプト文字列からJSON文字列を返す関数を注入するアダプタです。対象日・イベント・年齢層・ジャンル・任意条件・過去実績をプロンプトに含め、必須項目・10件・一意なタイトル・スコア範囲などを保存前に検証します。接続失敗・不正な応答は保存せず画面にエラーを表示します。テストではモデルの代わりの関数を使ってこの経路を確認しています。
- **実AIはまだ接続していません。** 現在の`get_generator()`は無料テスト生成器だけを返します。将来は無料のローカルモデルを別途準備し、その実行関数を`JsonThemeGenerator`へ渡すか、Protocolを満たす別の生成器を返します。モデルのライセンス・ハードウェア要件・出力品質は接続時に確認が必要です。モデルのダウンロード、有料API、任意の外部エンドポイントへの自動接続は行いません。
- Canva・TikTok連携、自動制作・自動投稿はPhase 1の対象外です。「投稿済み」は手動の進捗記録です。

## データ・運用

- 標準保存先はリポジトリ内 `data/studio.sqlite3`。テーマ、企画条件、判断・編集履歴、進捗、手入力実績、施設候補、項目別出典、写真の権利情報を保持します。再起動しても残ります。再生成は新しい企画履歴となり、既存企画を削除しません。施設・出典・写真は最新の内容と更新日時を保存し、変更前の全履歴は現段階では保存しません。
- 保存先を変更する場合は起動前に `MAKASE_DB_PATH` を指定します。PowerShell例：`$env:MAKASE_DB_PATH = 'C:\makase-data\studio.sqlite3'`。
- バックアップ時はアプリを停止し、`data` フォルダ全体をコピーしてください（WALファイルも対象）。バックアップも機密情報として扱ってください。DB・仮想環境はGit管理対象外です。
- 個人のローカル管理用です。ログイン、ユーザー別権限、インターネット公開用の保護はありません。既定のループバックで運用してください。同時更新はバージョン照合で古い内容による上書きを防ぎますが、共同編集UIはありません。
- 依存関係の直接バージョンを固定しています。完全な推移依存ロック／Windows実機検証は今後の課題です。
- `.env`やAPIキーを用意する必要はありません。`.env`とその派生、Streamlit秘密設定、DB、鍵ファイル、仮想環境、キャッシュはGit除外対象です。独自の名前で作った秘密ファイルまで自動で保護する保証はないため、コミット前には送信ファイル一覧も確認してください。

## テスト

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m pytest -q
```

Linuxでは `.venv/bin/python -m pip install -r requirements-dev.txt` と `.venv/bin/python -m pytest -q` を使用します。テストは一時DBを使用し、実データを書き換えません。既存のPhase 1テストを維持し、施設登録・比較・出典編集・写真許諾・期限・承認取り消し・更新競合・旧DBへの追加テーブル作成・AI応答検証のテストも追加しています。
