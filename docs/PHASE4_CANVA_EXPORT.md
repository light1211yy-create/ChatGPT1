# Phase 4 MVP｜Canva制作パック（7ページ・オフライン）

## 目的
承認済みテーマに結びついた施設候補のうち5件を選び、既存の**上下2枚の写真を使うCanva無料テンプレート**へ転記するための、下書き7ページ分をZIPで一括書き出します。

今回のMVPは既存テンプレートの自動編集・画像ダウンロード・動画作成・TikTok投稿は行いません。現時点で真に自動化できる「施設情報→7ページのコピー/配置情報/権利チェック情報の整形」を先に完了させ、無料枠と既存資産を維持します。

## 操作

1. GitHub Desktopで最新版を取得し、MAKASEを起動。既存の `data` と `.streamlit/secrets.toml` を保持。
2. 「AI投稿テーマ企画」でテーマを承認。
3. 「施設候補リサーチ」でAI調査案を利用する場合は5件を施設管理に明示登録。5件の施設は別途手動登録でも可。
4. 「施設候補リサーチ」内の「Canva用7ページ制作パック（Phase 4）」を開く。
5. 見送り以外の施設を**5件**、順序を意識して選択する。
6. 「Canva用7ページ制作パック（ZIP）を保存」を押し、ZIPの `pages.csv` と `README.md` を使ってCanvaの既存テンプレートへ手動配置する。
7. `source_checklist.csv` で公式情報、`photo_rights.csv` で素材の許諾条件を確認し、必要な修正・差し替えを行う。

## ZIP構成

| ファイル | 内容 |
|---|---|
| `pages.csv` | 7ページ：表紙／施設紹介5件／締め、コピー・上下写真の掲載元URL・制作メモ |
| `README.md` | ページ別指示・配置方法・公開前チェックリスト |
| `source_checklist.csv` | 5施設の所在地・公式サイト候補・料金の記録値（未検証扱い） |
| `photo_rights.csv` | 各写真の権利者・利用期限・許諾範囲・採用可否の確認状況 |
| `manifest.json` | ページ構成・施設ID・使える写真参照の件数・非自動化事項 |

CSVはExcelで開いたときに式として評価されやすい入力値をエスケープします。名前や出典に外部由来の文字列が混ざる場合の安全対策です。

## 写真の扱い

- 写真ファイル自体は**絶対にダウンロード・埋め込みしない**。
- 施設の写真候補に「利用可」の記録があっても、それだけではスライド候補にしない。利用状況が期限内で、権利者・許諾根拠・商用用途・SNS/TikTok・加工/文字重ねの記録をすべて満たす場合に限り、掲載元の参照URLをスライドの上下候補枠へ出す。
- 記録はユーザー申告ベースであり、写真と実施設の一致・許諾が法的に有効かは自動検証できない。必ず公開前に人が確認。
- 条件を満たさない写真はページの枠を空欄にして `photo_rights.csv` に確認対象として残す。
- 画像出典のクレジット表記と再利用規約を確認する。公式/予約サイトの写真を自動転載しない。

## 品質と制約

- 施設名以外の情報は参考/要公式確認として扱い、AIの推測した価格・営業状況・施設のメリットを新規に創作しない。
- タイトルと施設の順序は選択結果に基づく。本文・キャプションの高度なAI校正は**次の開発ステップ**で追加予定。
- ZIPはメモリで生成し、SQLiteの制作状況・写真許諾・承認情報を変更しない。秘密設定や外部APIを読み取らない。
- CanvaのBulk Createなど、有料・提供状況の異なる機能への依存なし。
- Windows/Canva実機のインポートやTikTokの実投稿は未検証。

## 速度重視の次の開発

1. **Phase 4.1**：7ページZIPを実際に1本制作して、欠けている素材・文章・権利情報を特定。
2. **Phase 4.2**：Gemini 3.5 Flash-Liteによる紹介文・保存訴求・キャプションの一括生成を明示同意付きで追加。3.8 Flashは将来の標準候補として維持。
3. **Phase 4.3**：既存Canvaテンプレートを破壊せずに編集できる公式手段/権限を検証。無料プランと許諾された素材に限定して自動配置する。
4. **Phase 5**：TikTok下書きとの連携を公式API/規約・権限を確認して実装。無承認の公開・規約に反した自動操作は禁止。

目標指標：1投稿あたりの制作時間、手入力する項目数、情報・素材の確認待ち件数、公開前の修正回数を比較する。テストは架空施設・一時SQLiteのみ、実API通信なしで実行する。
