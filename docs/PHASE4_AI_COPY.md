# Phase 4.2｜確認後に使う7ページ原稿・キャプション案

対象：Issue [#7](https://github.com/light1211yy-create/ChatGPT1/issues/7)。基準main：`4d93e8f`。既存の[オフライン制作パック](PHASE4_CANVA_EXPORT.md)に追加する任意機能。Canva編集・画像取得・投稿・スケジュール実行は行わない。

## 操作

1. 「施設候補リサーチ」で承認済みテーマを開き、「Canva用7ページ制作パック」で見送り以外の5施設を選び、順番を確認する。AIを選ばなくても従来のZIPを保存できる。
2. 必要な場合だけ「AIコピー案を作成・編集する」を選ぶ。事実を入れる場合は、今回自分で公式情報を確認した項目別出典を選ぶ。未選択なら事実を含まない中立的な候補紹介になる。
3. 出典は登録された公式URLと同じホスト（`www.`の有無は許容）、確認日が日本時間の今日以前、事実50文字以内、1施設2件・全体10件まで。OSMの登録情報・未確認／要確認・指示文は使えない。サイトの真正性・内容の正しさ・情報の鮮度は本人が確認する。ホスト一致と日付だけではアプリの公式検証にならない。短い事実を記録し、広告文や口コミを転載しない。
4. 送信するテーマ名・施設ID／名称・選択した短い事実／出典URL／確認日を確認する。施設メモ・住所・未確認料金・写真・権利資料・過去実績・キーはプロンプトに含めない。定型文と出力の制約も一緒に送る。
5. モデルを明示選択する。既定は既存どおり`gemini-3.8-flash`／MEDIUM。テスト用に`gemini-3.5-flash-lite`／MINIMALを手動選択できる。自動切替なし。今回、モデル資格・料金表を新たに検証したという意味ではない。
6. 公式料金表の無料枠、**実際のキーが属する**Free tierプロジェクトのBilling無効、確認した内容の今回1回の送信、の3つを確認し「AIでコピー案を作成」を押す。確認不足ではキーを読まず送信しない。モデル・入力・出典・試行が変わればチェックを取り直す。
7. 表紙＋5施設＋締めの7ページ、キャプション、タグを編集し、事実と出典を確認して「編集した原稿を確認済みにする」を押す。その後「確認済みAI原稿をZIPに含める」を選び、ZIPを保存する。これは公開・Canva操作の承認ではない。

## 生成範囲と検証

施設固有の事実を自由生成させると出典のない設備・料金等を紛れ込ませるため、今回は**制約付きの選択・組み合わせ**とする。AIは短い中立的な編集文、選択済み出典の正確な事実、表紙・締め・キャプション・タグの定型候補から原稿を組み立てる。外部データ内の指示には従わせず、選択肢外の文章・別施設の出典・架空の事実・余分なフィールドを応答検証で拒否する。事実は引用元の確認を本人が行った範囲であり、AI／アプリが真実性を保証するものではない。

人による編集は自由記述を認める。追加・変更した事実の公式確認も最終チェックの対象になる。機械的な意味判定で真実性を保証できないため、編集後は必ず本人が全ページを確認する。写真の使用許可は原稿の確認から推定しない。

- JSONは厳密に7ページ・5施設の指定順・必須項目・型・出典対応・重複キーを検証する。
- 見出し40文字、本文100文字、キャプション600文字、タグ1〜8件（各20文字）まで。空欄・秘密情報らしい文字列・超過は拒否し、自動切り詰めなし。長い施設名も短縮せず停止する。これらは安全な文字数上限であり、実テンプレートへの収まりを保証しない。
- SDKは既存`google-genai==3.0.0`。Developer APIへの1リクエスト、HTTPタイムアウト120秒、リトライ試行数1、toolsなし、関数自動呼出し無効。Web検索・Grounding・有料切替なし。APIキーだけで無料枠／課金状態をアプリから証明できないため、本人確認を必須にする。
- HTTP 408／504の応答、429の利用枠不足、401／403、404、その他APIエラーとクライアント側通信タイムアウトを安全な日本語で表示する。生の例外・キーを表示しない。失敗・拒否・不正応答では採用せず、再試行は新しい確認後の本人操作に限る。

## データ・原稿の版・ZIP

DBスキーマ変更なし。原稿生成・編集・確認はブラウザセッションのメモリだけで扱い、SQLite・写真の`permission_status`・承認履歴を更新しない。ブラウザ終了／再接続・サーバー再起動を越える未保存原稿の保持は保証しない。必要な成果物はZIPで本人が保存する。

テーマ／承認状態、5施設／順番、施設・出典の版／内容を照合する。生成中・確認時・書き出し時に変わっていれば、古い原稿は採用不可。以前の文は閲覧用に残すが、再生成して確認し直す。編集すると確認済み状態とZIP追加の選択が外れる。写真は書き出し時の権利・期限で再評価し、未確認・期限切れ・用途／編集条件不足の写真を枠へ入れない。

AIなしのZIPは従来の5ファイルのまま。確認済みAI原稿を明示追加した場合だけ、`pages.csv`の見出し／本文、`manifest.json`のモデル・生成日時・確認日時・出典対応・原稿、`caption.txt`を追加・反映する。CSVの式対策は従来どおり。写真URLは参照先で、写真ファイルは含まない。Canvaの元テンプレート・レイアウト・フォントは変更しない。
